Docs

How to run the TUI, the CLI commands, and what each manager does.

Run

With no arguments, NxtUpdate opens the TUI. Arrow keys to move, Enter to confirm, Ctrl+C to quit. 

nxtupdate
nxtupdate tui

TUI screens

Scan
Detects managers and outdated packages.
Menu
Update, list, or uninstall.
Select
Pick exactly which packages to touch.
Update
Live progress, one manager at a time.

CLI commands

nxtupdate scan
nxtupdate list
nxtupdate update
nxtupdate update --only homebrew
nxtupdate update --only npm

Options

Flag Commands Effect
-o, --only <manager> update, list Target a single package manager.
-d, --dry-run tui, update Preview only. No changes.
--no-sudo tui, update Skip macOS system updates.
-v, --verbose update Print package names while updating.
-y, --yes update, list Skip confirmation prompts.

Detected managers

Manager Command Notes
Homebrew brew Formulae and casks.
Node.js npm / pnpm / yarn / bun Uses the active package manager.
Python pip3 / pip Skips virtualenvs and externally managed environments.
Rust / Cargo cargo Needs cargo-install-update.
macOS softwareupdate Runs with sudo.

Cargo

Cargo cannot list outdated packages on its own. Install this once: 

cargo install cargo-install-update

Bun

NxtUpdate runs on Bun 1.0 or later.

curl -fsSL https://bun.sh/install | bash
